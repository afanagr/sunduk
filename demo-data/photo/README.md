# Photo

Демонстрационная галерея (каталог `photo` в панели, полный доступ на запись).

Файлы `photo-1.png` и `logo.svg` добавлены, чтобы протестировать
предпросмотр изображений и правила безопасности:

* PNG отдаётся inline, показывается в полноэкранном просмотрщике (`/api/preview`)
  и в плиточном режиме — переключатель ▦ в панели инструментов.
* SVG всегда принудительно скачивается как `application/octet-stream`,
  чтобы исключить stored-XSS через встроенные скрипты.
