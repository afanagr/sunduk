# План проекта «Сундук»

## Цель
Развернуть self-hosted файловый менеджер с доступом из локальной сети и
возможностью выдавать внешние ссылки на отдельные файлы и папки.

## Этапы
| Этап | Содержание | Статус |
|------|------------|--------|
| 1 | Инфраструктура Docker (два порта, hardening) | готово |
| 2 | Админ-API: файловые операции | готово |
| 3 | Ссылки: создание, пароль, срок, лимит скачиваний | готово |
| 4 | Веб-интерфейс администратора | готово |
| 5 | Публичная страница ссылки | готово |
| 6 | Проверка на реальном хранилище | в работе |

## Заметки
* Публичный порт открывается наружу, админ-порт — только LAN.
* Пароль администратора хранится scrypt-хешем в базе, а не в файле настроек.
* Ключ сессий и шифрования ссылок — в `/data/secret.key` (создаётся при первом
  запуске и переиспользуется, поэтому его нужно включать в бэкап).
