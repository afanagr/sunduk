# Files

Общий доступ к документам. Каталог `files` добавлен с полным доступом:
загрузка, создание папок, переименование, перемещение, копирование и удаление.

Демонстрационная структура:

```
Files/
├── README.md
├── Documents/
│   ├── Budget.csv
│   └── Project-Plan.md
└── Inbox/
    └── README.txt
```

Проверьте drag & drop: перетащите любой файл в окно браузера — он попадёт
в текущую открытую папку.
