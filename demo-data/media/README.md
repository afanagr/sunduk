# Media

Этот каталог добавлен в Сундуке под именем `media` — с полным доступом на запись.

Через интерфейс можно:
* просматривать содержимое и открывать медиа в полноэкранном просмотрщике
  (‹/› — листание по папке, плиточный режим с миниатюрами),
* загружать файлы, создавать папки, переименовывать, перемещать, копировать и
  удалять,
* скачивать файлы,
* создавать публичные ссылки (в том числе с паролем и сроком действия).

В `Demos/` лежат два файла, показывающие онлайн-просмотр без скачивания:
`demo-tone.wav` (короткий тон) и `demo-document.pdf`. Видео и аудио отдаются
потоком с поддержкой HTTP Range, поэтому перемотка работает сразу.

В `Movies/` лежит текстовый файл — на нём удобно проверить ссылку на отдельный
файл (кнопка 🔗 рядом с файлом в панели).

Замените эти файлы своими или подключите в панели настоящий каталог сервера:
каталоги задаются в интерфейсе, переменных окружения у Сундука нет.
